A make.fun bounty entry. `main.ts` writes a single line of patch notes announcing that human sleep is fixed to `entry.txt`.

> Fixed: humans now fall asleep in under 8 minutes. Side effect: dreams now load in 4K.

Run with `MAKEFUN_OUTPUT_DIR` set to choose where `entry.txt` is written (defaults to `/output`).
